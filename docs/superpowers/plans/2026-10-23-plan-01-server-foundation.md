# Plan 1: Server foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running, fully tested Spring Boot server with error handling, logging, code rules, email OTP login, rotating refresh tokens, profile and fixed costs, budget cycles, the budget engine and `GET /api/v1/budget/today`.

**Architecture:** One Spring Boot application in `server/`, packaged by feature (`auth`, `profile`, `budget`, `content`, `common`). Data access with Spring's `JdbcClient` and Flyway migrations on Postgres. Stateless JWT access tokens (HS256, 15 minutes) plus opaque single-use refresh tokens stored hashed. Pure calculators (`CycleCalculator`, `BudgetCalculator`) hold the money rules and are unit-tested without Spring; everything else is tested through MockMvc against Postgres in Testcontainers.

**Tech Stack:** Java 21, Spring Boot (latest stable 4.x line, generated by Spring Initializr), Spring Security OAuth2 resource server (Nimbus JWT), Spring JDBC (`JdbcClient`), Flyway, PostgreSQL 17, Testcontainers, JUnit 5, AssertJ, MockMvc, ArchUnit, Gradle (Kotlin DSL).

**Spec:** `docs/superpowers/specs/2026-10-23-gullak-v1-design.md`, with test cases in `docs/superpowers/specs/2026-10-23-gullak-v1-test-cases.md` and rules in `docs/engineering-standards.md`. Read all three before starting any task.

## Global Constraints

- Money is `long` paise everywhere. No `double`, `float` or `BigDecimal` for amounts. Budget division rounds down.
- Day boundaries use `Asia/Kolkata`. Timestamps are stored as `timestamptz` and handled as `Instant`/`OffsetDateTime` in UTC.
- Every query on user data filters by the user ID taken from the JWT subject. No endpoint accepts a user ID from the client. Another user's object returns 404.
- Error bodies are `{code, message}` (plus `fields` for validation and `errorId` for 500s). Codes come from `in.gullak.common.error.ErrorCode`.
- Never log amounts, merchant text, emails, UPI handles, tokens, passwords or OTP codes. Parameterised logging only.
- No empty catch blocks; no `catch (Exception`, `catch (RuntimeException` or `catch (Throwable` outside `common/error`.
- Constructor injection only. Records for request and response bodies. Controllers never touch `JdbcClient`.
- API base path `/api/v1`. JSON enums are the Java constant names (`FIXED_DAY`, `CHILL`).
- User-facing messages follow `.claude/design.md` copy rules: sentence case; a single sentence has no full stop; two or more sentences take a full stop after each.
- Each task's owner is named; after the owner hands back, `qa-engineer` runs, then `red-team` where the task says so, then `manager` reviews (`docs/team.md`).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A spend at 23:59:59 IST and one at 00:00:01 IST land on different days even though the server runs in UTC. Pinned in Task 10 (BUD-28 test).
- Two requests that both create the first cycle at the same moment produce one cycle row, not two. Pinned in Task 10 (`concurrentFirstRequestsCreateOneCycle`).
- `" Priya@Example.COM "` and `"priya@example.com"` sign in to the same account. Pinned in Task 5 (`emailIsNormalised`).
- Two refreshes racing with the same refresh token: exactly one succeeds and the token family is revoked. Pinned in Task 6 (`parallelRefreshWithSameTokenRevokesFamily`).
- An `X-Request-Id` header with a newline or 500 characters is not echoed into logs or responses. Pinned in Task 3 (`unsafeRequestIdIsReplaced`).

## Deviations from the spec, decided here

- Data access uses `JdbcClient` everywhere instead of JPA for simple cases (spec 4.3 allows JDBC; one style is simpler for a solo team and avoids lazy-loading surprises). Task 1 updates spec 4.3 to say so.
- Empty-catch and broad-catch rules are enforced by a source-rules test (Task 4) rather than ArchUnit, which cannot see catch blocks. ArchUnit still checks architecture. Task 4 updates `docs/engineering-standards.md` section 3.
- A payday change mid-cycle keeps the current cycle; the next cycle starts the day after it ends and runs to the day before the new payday (a short bridge), then normal cycles follow. Task 10 updates BUD-18 and API-PRO-10 in the test-cases doc.
- `GET /budget/today` returns budget, spend, mood, line and cycle dates. Streak, forecast and catch-up fields are added by Plans 5 and 6.
- The OTP mailer in this plan is an in-memory implementation for the `local` and `test` profiles only. The real email provider is Plan 8; until then the `prod` profile refuses to start without a mailer bean, which is the safe failure.

```java
package in.gullak.common.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.http.HttpMethod;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.config.http.SessionCreationPolicy;
import org.springframework.security.web.SecurityFilterChain;

@Configuration
@EnableWebSecurity
public class SecurityConfig {
    @Bean
    SecurityFilterChain api(HttpSecurity http) throws Exception {
        http.csrf(c -> c.disable())
            .httpBasic(b -> b.disable())
            .formLogin(f -> f.disable())
            .sessionManagement(s -> s.sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(a -> a
                .requestMatchers(HttpMethod.GET, "/actuator/health").permitAll()
                .anyRequest().authenticated());
        return http.build();
    }
}
```

```java
package in.gullak.support;

import java.time.Clock;
import java.time.Duration;
import java.time.Instant;
import java.time.ZoneId;
import java.time.ZoneOffset;

public class MutableClock extends Clock {
    public static final Instant DEFAULT = Instant.parse("2026-10-23T08:00:00Z");
    private volatile Instant now = DEFAULT;

    public void set(Instant instant) { this.now = instant; }
    public void advance(Duration duration) { this.now = now.plus(duration); }
    public void reset() { this.now = DEFAULT; }

    @Override public ZoneId getZone() { return ZoneOffset.UTC; }
    @Override public Clock withZone(ZoneId zone) { return Clock.fixed(now, zone); }
    @Override public Instant instant() { return now; }
}
```

```java
import java.util.List;
import java.util.UUID;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.web.HttpMediaTypeNotSupportedException;
import org.springframework.web.HttpRequestMethodNotSupportedException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.MissingServletRequestParameterException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;
import org.springframework.web.method.annotation.HandlerMethodValidationException;
import org.springframework.web.method.annotation.MethodArgumentTypeMismatchException;
import org.springframework.web.multipart.MaxUploadSizeExceededException;
import org.springframework.web.servlet.resource.NoResourceFoundException;

@RestControllerAdvice
public class GlobalExceptionHandler {
    private static final Logger log = LoggerFactory.getLogger(GlobalExceptionHandler.class);
    private static final String CHECK_FIELDS = "Check the highlighted fields";

    @ExceptionHandler(GullakException.class)
    ResponseEntity<ErrorBody> gullak(GullakException e) {
        if (e.code().warn()) {
            log.warn("error.expected code={}", e.code());
        }
        return ResponseEntity.status(e.status()).body(ErrorBody.of(e.code(), e.getMessage()));
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    ResponseEntity<ErrorBody> invalidBody(MethodArgumentNotValidException e) {
        List<ErrorBody.FieldProblem> fields = e.getBindingResult().getFieldErrors().stream()
            .map(f -> new ErrorBody.FieldProblem(f.getField(), f.getDefaultMessage()))
            .toList();
        return badRequest(fields);
    }

    @ExceptionHandler(HandlerMethodValidationException.class)
    ResponseEntity<ErrorBody> invalidParameters(HandlerMethodValidationException e) {
        List<ErrorBody.FieldProblem> fields = e.getParameterValidationResults().stream()
            .flatMap(r -> r.getResolvableErrors().stream()
                .map(err -> new ErrorBody.FieldProblem(r.getMethodParameter().getParameterName(), err.getDefaultMessage())))
            .toList();
        return badRequest(fields);
    }

    @ExceptionHandler({
        HttpMessageNotReadableException.class,
        MethodArgumentTypeMismatchException.class,
        MissingServletRequestParameterException.class
    })
    ResponseEntity<ErrorBody> unreadable() {
        return badRequest(null);
    }

    @ExceptionHandler(MaxUploadSizeExceededException.class)
    ResponseEntity<ErrorBody> tooLarge() {
        return ResponseEntity.status(HttpStatus.PAYLOAD_TOO_LARGE)
            .body(ErrorBody.of(ErrorCode.TOO_LARGE, "That file is over 10 MB"));
    }

    @ExceptionHandler(NoResourceFoundException.class)
    ResponseEntity<ErrorBody> noRoute() {
        return ResponseEntity.status(HttpStatus.NOT_FOUND).body(ErrorBody.of(ErrorCode.NOT_FOUND, "Not found"));
    }

    @ExceptionHandler(HttpRequestMethodNotSupportedException.class)
    ResponseEntity<ErrorBody> wrongMethod() {
        return ResponseEntity.status(HttpStatus.METHOD_NOT_ALLOWED)
            .body(ErrorBody.of(ErrorCode.METHOD_NOT_ALLOWED, "That action isn't supported here"));
    }

    @ExceptionHandler(HttpMediaTypeNotSupportedException.class)
    ResponseEntity<ErrorBody> wrongMediaType() {
        return ResponseEntity.status(HttpStatus.UNSUPPORTED_MEDIA_TYPE)
            .body(ErrorBody.of(ErrorCode.UNSUPPORTED_MEDIA_TYPE, "Send JSON"));
    }

    @ExceptionHandler(Exception.class)
    ResponseEntity<ErrorBody> unexpected(Exception e) {
        String errorId = UUID.randomUUID().toString();
        log.error("error.unexpected errorId={}", errorId, e);
        return ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR)
            .body(new ErrorBody(ErrorCode.INTERNAL.name(), "Something went wrong", null, errorId));
    }

    private static ResponseEntity<ErrorBody> badRequest(List<ErrorBody.FieldProblem> fields) {
        return ResponseEntity.badRequest()
            .body(new ErrorBody(ErrorCode.VALIDATION.name(), CHECK_FIELDS, fields, null));
    }
```

```java
import org.springframework.stereotype.Component;

/** Writes 401 and 403 responses from the security filters in the standard error shape. */
@Component
public class JsonAuthHandlers implements AuthenticationEntryPoint, AccessDeniedHandler {

    @Override
    public void commence(HttpServletRequest request, HttpServletResponse response, AuthenticationException ex)
            throws IOException {
        String detail = ex.getMessage() == null ? "" : ex.getMessage().toLowerCase(Locale.ROOT);
        if (detail.contains("expired")) {
            write(response, 401, ErrorCode.TOKEN_EXPIRED, "Your session has expired");
        } else {
            write(response, 401, ErrorCode.UNAUTHENTICATED, "Sign in to continue");
        }
    }

    @Override
    public void handle(HttpServletRequest request, HttpServletResponse response, AccessDeniedException ex)
            throws IOException {
        write(response, 403, ErrorCode.FORBIDDEN, "Not allowed");
    }

            throws IOException {
        response.setStatus(status);
        response.setContentType("application/json");
        response.setCharacterEncoding("UTF-8");
        response.getWriter().write("{\"code\":\"" + code.name() + "\",\"message\":\"" + message + "\"}");
```

```java
package in.gullak.common.log;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.util.UUID;
import java.util.regex.Pattern;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.slf4j.MDC;
import org.springframework.core.Ordered;
import org.springframework.core.annotation.Order;
import org.springframework.stereotype.Component;
import org.springframework.web.filter.OncePerRequestFilter;
import org.springframework.web.servlet.HandlerMapping;

/** Gives every request an id and writes exactly one INFO line when it finishes. */
@Component
@Order(Ordered.HIGHEST_PRECEDENCE)
public class RequestLogFilter extends OncePerRequestFilter {
    public static final String HEADER = "X-Request-Id";
    private static final Logger log = LoggerFactory.getLogger(RequestLogFilter.class);
    private static final Pattern SAFE_ID = Pattern.compile("[A-Za-z0-9-]{8,64}");

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain chain)
            throws ServletException, IOException {
        String incoming = request.getHeader(HEADER);
        String requestId = incoming != null && SAFE_ID.matcher(incoming).matches()
            ? incoming
            : UUID.randomUUID().toString();
        long start = System.nanoTime();
        MDC.put("requestId", requestId);
        response.setHeader(HEADER, requestId);
        try {
            chain.doFilter(request, response);
        } finally {
            Object pattern = request.getAttribute(HandlerMapping.BEST_MATCHING_PATTERN_ATTRIBUTE);
            String route = pattern != null ? pattern.toString() : "unmatched";
            log.info("http method={} route={} status={} ms={}",
                request.getMethod(), route, response.getStatus(), (System.nanoTime() - start) / 1_000_000);
            MDC.clear();
        }
    }
}
```

The route is the matched pattern (`/api/v1/transactions/{id}`), never the raw path, so ids and query strings never reach the log.

```java
package in.gullak.common.web;

import in.gullak.common.error.RateLimitedException;
import java.time.Clock;
import java.time.Duration;
import java.time.Instant;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicInteger;
import org.springframework.stereotype.Component;

/**
 * Fixed-window limiter in memory. Correct for one server instance; Plan 9 revisits it if we run more.
 */
@Component
public class RateLimiter {
    private record Window(Instant start, Duration length, int count) {}

    private final Clock clock;
    private final ConcurrentHashMap<String, Window> windows = new ConcurrentHashMap<>();
    private final AtomicInteger calls = new AtomicInteger();

    public RateLimiter(Clock clock) {
        this.clock = clock;
    }

    public void check(String key, int limit, Duration window) {
        Instant now = clock.instant();
        Window w = windows.compute(key, (k, old) ->
            old == null || !now.isBefore(old.start().plus(old.length()))
                ? new Window(now, window, 1)
                : new Window(old.start(), old.length(), old.count() + 1));
        if (calls.incrementAndGet() % 1000 == 0) {
            windows.entrySet().removeIf(e -> !now.isBefore(e.getValue().start().plus(e.getValue().length())));
        }
        if (w.count() > limit) {
            throw new RateLimitedException();
        }
    }
}
```

```java
package in.gullak.auth;

import java.nio.charset.StandardCharsets;
import java.security.GeneralSecurityException;
import java.security.MessageDigest;
import java.util.HexFormat;
import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import org.springframework.stereotype.Component;

/** HMAC with a server-side pepper, so a leaked table does not reveal codes. */
@Component
class OtpHasher {
    private final SecretKeySpec key;

    OtpHasher(AuthProperties props) {
        this.key = new SecretKeySpec(props.otpPepper().getBytes(StandardCharsets.UTF_8), "HmacSHA256");
    }

    String hash(String email, String code) {
        try {
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(key);
            return HexFormat.of().formatHex(mac.doFinal((email + ":" + code).getBytes(StandardCharsets.UTF_8)));
        } catch (GeneralSecurityException e) {
            throw new IllegalStateException("HMAC-SHA256 is not available", e);
        }
    }

    boolean matches(String email, String code, String expectedHash) {
        return MessageDigest.isEqual(
            hash(email, code).getBytes(StandardCharsets.UTF_8),
            expectedHash.getBytes(StandardCharsets.UTF_8));
    }
}
```

```java
package in.gullak.auth;

import in.gullak.common.db.Db;
import in.gullak.common.error.AuthException;
import in.gullak.common.error.ErrorCode;
import in.gullak.common.error.GullakException;
import in.gullak.common.log.Events;
import in.gullak.common.web.RateLimiter;
import java.security.SecureRandom;
import java.time.Clock;
import java.time.Duration;
import java.time.Instant;
import java.time.OffsetDateTime;
import java.util.UUID;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class OtpService {
    static final int MAX_ATTEMPTS = 5;
    private static final Logger log = LoggerFactory.getLogger(OtpService.class);
    private static final Duration WINDOW = Duration.ofMinutes(10);

    private record OtpRow(UUID id, String codeHash, Instant expiresAt, int attempts) {}

    private final JdbcClient jdbc;
    private final OtpMailer mailer;
    private final OtpHasher hasher;
    private final RateLimiter limiter;
    private final UserRepository users;
    private final AuthProperties props;
    private final Clock clock;
    private final SecureRandom random = new SecureRandom();

    OtpService(JdbcClient jdbc, OtpMailer mailer, OtpHasher hasher, RateLimiter limiter,
               UserRepository users, AuthProperties props, Clock clock) {
        this.jdbc = jdbc;
        this.mailer = mailer;
        this.hasher = hasher;
        this.limiter = limiter;
        this.users = users;
        this.props = props;
        this.clock = clock;
    }

    public void request(String rawEmail, String ip) {
        String email = Emails.normalize(rawEmail);
        limiter.check("otp-request-email:" + email, 5, WINDOW);
        limiter.check("otp-request-ip:" + ip, 30, WINDOW);
        String code = String.format("%06d", random.nextInt(1_000_000));
        jdbc.sql("insert into otp_codes (id, email, code_hash, expires_at) values (?, ?, ?, ?)")
            .params(UUID.randomUUID(), email, hasher.hash(email, code), Db.ts(clock.instant().plus(props.otpTtl())))
            .update();
        mailer.sendOtp(email, code);
        log.info(Events.AUTH_OTP_REQUESTED);
    }

    @Transactional(noRollbackFor = GullakException.class)
    public UUID verify(String rawEmail, String code, String ip) {
        String email = Emails.normalize(rawEmail);
        limiter.check("otp-verify-ip:" + ip, 30, WINDOW);
        OtpRow otp = jdbc.sql("""
                select id, code_hash, expires_at, attempts from otp_codes
                where email = ? and consumed_at is null
                order by created_at desc limit 1
                for update
                """)
            .param(email)
            .query((rs, n) -> new OtpRow(
                rs.getObject("id", UUID.class),
                rs.getString("code_hash"),
                rs.getObject("expires_at", OffsetDateTime.class).toInstant(),
                rs.getInt("attempts")))
            .optional()
            .orElseThrow(() -> new AuthException(ErrorCode.OTP_INVALID, "That code didn't work. Request a new one."));

        if (otp.attempts() >= MAX_ATTEMPTS) {
            throw new AuthException(ErrorCode.OTP_LOCKED, "Too many tries. Request a new code.");
        }
        if (!clock.instant().isBefore(otp.expiresAt())) {
            throw new AuthException(ErrorCode.OTP_EXPIRED, "That code has expired. Request a new one.");
        }
        if (!hasher.matches(email, code, otp.codeHash())) {
            jdbc.sql("update otp_codes set attempts = attempts + 1 where id = ?").param(otp.id()).update();
            throw new AuthException(ErrorCode.OTP_INVALID, "That code didn't work. Check it and try again.");
        }
        jdbc.sql("update otp_codes set consumed_at = ? where id = ?")
            .params(Db.ts(clock.instant()), otp.id()).update();
        UUID userId = users.findOrCreate(email);
        log.info("{} user={}", Events.AUTH_OTP_VERIFIED, userId);
        return userId;
    }
}
```

```java
package in.gullak.auth;

import in.gullak.common.db.Db;
import in.gullak.common.error.AuthException;
import in.gullak.common.error.ErrorCode;
import in.gullak.common.error.GullakException;
import in.gullak.common.log.Events;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.security.SecureRandom;
import java.time.Clock;
import java.time.Instant;
import java.time.OffsetDateTime;
import java.util.Base64;
import java.util.HexFormat;
import java.util.Optional;
import java.util.UUID;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.security.oauth2.jose.jws.MacAlgorithm;
import org.springframework.security.oauth2.jwt.JwsHeader;
import org.springframework.security.oauth2.jwt.JwtClaimsSet;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.JwtEncoderParameters;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class TokenService {
    private static final Logger log = LoggerFactory.getLogger(TokenService.class);

    private record RefreshRow(UUID id, UUID userId, UUID familyId, String device, Instant expiresAt,
                              Instant usedAt, Instant revokedAt) {}

    private final JwtEncoder encoder;
    private final JdbcClient jdbc;
    private final AuthProperties props;
    private final Clock clock;
    private final SecureRandom random = new SecureRandom();

    TokenService(JwtEncoder encoder, JdbcClient jdbc, AuthProperties props, Clock clock) {
        this.encoder = encoder;
        this.jdbc = jdbc;
        this.props = props;
        this.clock = clock;
    }

    public TokenPair issue(UUID userId, String device) {
        return issueInFamily(userId, device, UUID.randomUUID());
    }

    @Transactional(noRollbackFor = GullakException.class)
    public TokenPair refresh(String refreshToken) {
        RefreshRow row = find(refreshToken)
            .orElseThrow(() -> new AuthException(ErrorCode.UNAUTHENTICATED, "Sign in to continue"));
        if (row.usedAt() != null || row.revokedAt() != null) {
            revokeAllFor(row.userId(), "reuse");
            throw new AuthException(ErrorCode.TOKEN_REUSED, "Please sign in again");
        }
        if (!clock.instant().isBefore(row.expiresAt())) {
            throw new AuthException(ErrorCode.TOKEN_EXPIRED, "Your session has expired");
        }
        int claimed = jdbc.sql("update refresh_tokens set used_at = ? where id = ? and used_at is null")
            .params(Db.ts(clock.instant()), row.id()).update();
        if (claimed == 0) {
            revokeAllFor(row.userId(), "race");
            throw new AuthException(ErrorCode.TOKEN_REUSED, "Please sign in again");
        }
        return issueInFamily(row.userId(), row.device(), row.familyId());
    }

    public void logout(String refreshToken) {
        find(refreshToken).ifPresent(row -> {
            jdbc.sql("update refresh_tokens set revoked_at = ? where family_id = ? and revoked_at is null")
                .params(Db.ts(clock.instant()), row.familyId()).update();
            log.info("{} user={} reason=logout", Events.AUTH_SESSION_REVOKED, row.userId());
        });
    }

    private TokenPair issueInFamily(UUID userId, String device, UUID familyId) {
        Instant now = clock.instant();
        JwtClaimsSet claims = JwtClaimsSet.builder()
            .issuer(JwtConfig.ISSUER)
            .subject(userId.toString())
            .issuedAt(now)
            .expiresAt(now.plus(props.accessTtl()))
            .build();
        String access = encoder.encode(
            JwtEncoderParameters.from(JwsHeader.with(MacAlgorithm.HS256).build(), claims)).getTokenValue();

        byte[] raw = new byte[32];
        random.nextBytes(raw);
        String refresh = Base64.getUrlEncoder().withoutPadding().encodeToString(raw);
        jdbc.sql("""
                insert into refresh_tokens (id, user_id, token_hash, family_id, device, expires_at)
                values (?, ?, ?, ?, ?, ?)
                """)
            .params(UUID.randomUUID(), userId, sha256(refresh), familyId, device,
                Db.ts(now.plus(props.refreshTtl())))
            .update();
        return new TokenPair(access, refresh, props.accessTtl().toSeconds());
    }

    private Optional<RefreshRow> find(String refreshToken) {
        return jdbc.sql("""
                select id, user_id, family_id, device, expires_at, used_at, revoked_at
                from refresh_tokens where token_hash = ?
                """)
            .param(sha256(refreshToken))
            .query((rs, n) -> new RefreshRow(
                rs.getObject("id", UUID.class),
                rs.getObject("user_id", UUID.class),
                rs.getObject("family_id", UUID.class),
                rs.getString("device"),
                rs.getObject("expires_at", OffsetDateTime.class).toInstant(),
                toInstant(rs.getObject("used_at", OffsetDateTime.class)),
                toInstant(rs.getObject("revoked_at", OffsetDateTime.class))))
            .optional();
    }

    private void revokeAllFor(UUID userId, String reason) {
        jdbc.sql("update refresh_tokens set revoked_at = ? where user_id = ? and revoked_at is null")
            .params(Db.ts(clock.instant()), userId).update();
        log.warn("{} user={} reason={}", Events.AUTH_SESSION_REVOKED, userId, reason);
    }

    private static Instant toInstant(OffsetDateTime t) {
        return t == null ? null : t.toInstant();
    }

    private static String sha256(String value) {
        try {
            byte[] digest = MessageDigest.getInstance("SHA-256").digest(value.getBytes(StandardCharsets.UTF_8));
            return HexFormat.of().formatHex(digest);
        } catch (NoSuchAlgorithmException e) {
            throw new IllegalStateException("SHA-256 is not available", e);
        }
    }
}
```

Refresh tokens are 256-bit random values, so a plain SHA-256 (no pepper) is enough to protect them at rest.

```java
package in.gullak.profile;

import java.time.LocalTime;
import java.util.Optional;
import java.util.UUID;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Repository;

@Repository
class ProfileRepository {
    private final JdbcClient jdbc;

    ProfileRepository(JdbcClient jdbc) {
        this.jdbc = jdbc;
    }

    Optional<Profile> find(UUID userId) {
        return jdbc.sql("""
                select user_id, income_paise, savings_paise, payday_rule, payday_day, personality,
                       morning_time, night_time, timezone
                from profiles where user_id = ?
                """)
            .param(userId)
            .query((rs, n) -> new Profile(
                rs.getObject("user_id", UUID.class),
                rs.getLong("income_paise"),
                rs.getLong("savings_paise"),
                PaydayRule.valueOf(rs.getString("payday_rule")),
                rs.getObject("payday_day", Integer.class),
                Personality.valueOf(rs.getString("personality")),
                rs.getObject("morning_time", LocalTime.class),
                rs.getObject("night_time", LocalTime.class),
                rs.getString("timezone")))
            .optional();
    }

    void upsert(Profile p) {
        jdbc.sql("""
                insert into profiles (user_id, income_paise, savings_paise, payday_rule, payday_day,
                                      personality, morning_time, night_time, timezone)
                values (?, ?, ?, ?, ?, ?, ?, ?, ?)
                on conflict (user_id) do update set
                    income_paise = excluded.income_paise,
                    savings_paise = excluded.savings_paise,
                    payday_rule = excluded.payday_rule,
                    payday_day = excluded.payday_day,
                    personality = excluded.personality,
                    morning_time = excluded.morning_time,
                    night_time = excluded.night_time,
                    timezone = excluded.timezone,
                    updated_at = now()
                """)
            .params(p.userId(), p.incomePaise(), p.savingsPaise(), p.paydayRule().name(), p.paydayDay(),
                p.personality().name(), p.morningTime(), p.nightTime(), p.timezone())
            .update();
    }
}
```

```java
package in.gullak.profile;

import java.util.List;
import java.util.Optional;
import java.util.UUID;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Repository;

@Repository
class FixedCostRepository {
    private final JdbcClient jdbc;

    FixedCostRepository(JdbcClient jdbc) {
        this.jdbc = jdbc;
    }

    List<FixedCost> list(UUID userId) {
        return jdbc.sql("select id, name, amount_paise from fixed_costs where user_id = ? and active order by created_at")
            .param(userId)
            .query((rs, n) -> new FixedCost(rs.getObject("id", UUID.class), rs.getString("name"), rs.getLong("amount_paise")))
            .list();
    }

    Optional<FixedCost> find(UUID userId, UUID id) {
        return jdbc.sql("select id, name, amount_paise from fixed_costs where id = ? and user_id = ? and active")
            .params(id, userId)
            .query((rs, n) -> new FixedCost(rs.getObject("id", UUID.class), rs.getString("name"), rs.getLong("amount_paise")))
            .optional();
    }

    long total(UUID userId) {
        return jdbc.sql("select coalesce(sum(amount_paise), 0) from fixed_costs where user_id = ? and active")
            .param(userId).query(Long.class).single();
    }

    FixedCost insert(UUID userId, String name, long amountPaise) {
        UUID id = UUID.randomUUID();
        jdbc.sql("insert into fixed_costs (id, user_id, name, amount_paise) values (?, ?, ?, ?)")
            .params(id, userId, name, amountPaise).update();
        return new FixedCost(id, name, amountPaise);
    }

    void update(UUID userId, UUID id, String name, long amountPaise) {
        jdbc.sql("update fixed_costs set name = ?, amount_paise = ?, updated_at = now() where id = ? and user_id = ? and active")
            .params(name, amountPaise, id, userId).update();
    }

    boolean deactivate(UUID userId, UUID id) {
        return jdbc.sql("update fixed_costs set active = false, updated_at = now() where id = ? and user_id = ? and active")
            .params(id, userId).update() == 1;
    }
```

```java
package in.gullak.profile;

import in.gullak.common.error.ErrorCode;
import in.gullak.common.error.GullakException;
import in.gullak.common.error.UnprocessableException;
import in.gullak.common.error.ValidationException;
import in.gullak.common.log.Events;
import java.util.UUID;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.http.HttpStatus;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class ProfileService {
    private static final Logger log = LoggerFactory.getLogger(ProfileService.class);

    private final ProfileRepository profiles;
    private final FixedCostRepository fixedCosts;

    ProfileService(ProfileRepository profiles, FixedCostRepository fixedCosts) {
        this.profiles = profiles;
        this.fixedCosts = fixedCosts;
    }

    public Profile get(UUID userId) {
        return profiles.find(userId).orElseThrow(() -> new GullakException(
            ErrorCode.SETUP_INCOMPLETE, HttpStatus.CONFLICT, "Finish setup first"));
    }

    @Transactional
    public Profile put(UUID userId, ProfileRequest r) {
        Integer day = switch (r.paydayRule()) {
            case FIXED_DAY -> {
                if (r.paydayDay() == null) {
                    throw new ValidationException("Pick the day your salary arrives");
                }
                yield r.paydayDay();
            }
            case LAST_WORKING_DAY -> null;
        };
        requireSomethingToSpend(r.incomePaise(), fixedCosts.total(userId), r.savingsPaise());
        Profile p = new Profile(userId, r.incomePaise(), r.savingsPaise(), r.paydayRule(), day,
            r.personality(), r.morningTime(), r.nightTime(), r.timezone());
        profiles.upsert(p);
        log.info("{} user={}", Events.PROFILE_UPDATED, userId);
        return p;
    }

    /** Called by fixed-cost changes; does nothing before setup. */
    void checkWithFixedTotal(UUID userId, long newFixedTotal) {
        profiles.find(userId).ifPresent(p -> requireSomethingToSpend(p.incomePaise(), newFixedTotal, p.savingsPaise()));
    }

    static void requireSomethingToSpend(long income, long fixed, long savings) {
        if (income - fixed - savings <= 0) {
            long maxSavings = Math.max(0, income - fixed - 100);
            throw new UnprocessableException(ErrorCode.NOT_POSSIBLE,
                "Savings and fixed costs leave nothing to spend. Save " + in.gullak.common.money.RupeeFormat.format(maxSavings) + " or less.");
        }
    }
}
```

```java
package in.gullak.common.money;

/** Whole rupees with Indian digit grouping: 10000000 paise → "₹1,00,000". */
public final class RupeeFormat {
    private RupeeFormat() {}

    public static String format(long paise) {
        long rupees = Math.floorDiv(paise, 100);
        boolean negative = rupees < 0;
        String digits = Long.toString(Math.abs(rupees));
        if (digits.length() > 3) {
            String last3 = digits.substring(digits.length() - 3);
            String rest = digits.substring(0, digits.length() - 3);
            StringBuilder groups = new StringBuilder();
            while (rest.length() > 2) {
                groups.insert(0, "," + rest.substring(rest.length() - 2));
                rest = rest.substring(0, rest.length() - 2);
            }
            digits = rest + groups + "," + last3;
        }
        return (negative ? "−" : "") + "₹" + digits;
    }
}
```

```java
import java.util.List;
import java.util.UUID;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class FixedCostService {
    private static final Logger log = LoggerFactory.getLogger(FixedCostService.class);

    private final FixedCostRepository repo;
    private final ProfileService profiles;

    FixedCostService(FixedCostRepository repo, ProfileService profiles) {
        this.repo = repo;
        this.profiles = profiles;
    }

    public long totalFor(UUID userId) {
        return repo.total(userId);
    }

    List<FixedCost> list(UUID userId) {
        return repo.list(userId);
    }

    @Transactional
    FixedCost add(UUID userId, FixedCostRequest r) {
        profiles.checkWithFixedTotal(userId, repo.total(userId) + r.amountPaise());
        FixedCost created = repo.insert(userId, r.name().trim(), r.amountPaise());
        log.info("{} user={} id={} action=add", Events.FIXED_COST_CHANGED, userId, created.id());
        return created;
    }

    @Transactional
    FixedCost edit(UUID userId, UUID id, FixedCostPatch p) {
        FixedCost current = repo.find(userId, id).orElseThrow(() -> new NotFoundException("Fixed cost"));
        String name = p.name() != null ? p.name().trim() : current.name();
        long amount = p.amountPaise() != null ? p.amountPaise() : current.amountPaise();
        profiles.checkWithFixedTotal(userId, repo.total(userId) - current.amountPaise() + amount);
        repo.update(userId, id, name, amount);
        log.info("{} user={} id={} action=edit", Events.FIXED_COST_CHANGED, userId, id);
        return new FixedCost(id, name, amount);
    }

    @Transactional
    void remove(UUID userId, UUID id) {
        if (!repo.deactivate(userId, id)) {
            throw new NotFoundException("Fixed cost");
        }
        log.info("{} user={} id={} action=remove", Events.FIXED_COST_CHANGED, userId, id);
    }
}
```

```java
package in.gullak.budget;

import in.gullak.profile.PaydayRule;
import java.time.DayOfWeek;
import java.time.LocalDate;
import java.time.YearMonth;

public final class CycleCalculator {
    private CycleCalculator() {}

    public static LocalDate payday(YearMonth month, PaydayRule rule, Integer day) {
        return switch (rule) {
            case FIXED_DAY -> month.atDay(day);
            case LAST_WORKING_DAY -> {
                LocalDate d = month.atEndOfMonth();
                while (d.getDayOfWeek() == DayOfWeek.SATURDAY || d.getDayOfWeek() == DayOfWeek.SUNDAY) {
                    d = d.minusDays(1);
                }
                yield d;
            }
        };
    }

    /** The cycle that contains {@code date}: from a payday to the day before the next one. */
    public static Cycle containing(LocalDate date, PaydayRule rule, Integer day) {
        YearMonth month = YearMonth.from(date);
        LocalDate thisPayday = payday(month, rule, day);
        if (!date.isBefore(thisPayday)) {
            return new Cycle(thisPayday, payday(month.plusMonths(1), rule, day).minusDays(1));
        }
        return new Cycle(payday(month.minusMonths(1), rule, day), thisPayday.minusDays(1));
    }
}
```

```java
package in.gullak.budget;

/** The money rules of spec section 2.1. Pure: no clock, no database. */
public final class BudgetCalculator {
    private BudgetCalculator() {}

    public static DailyBudget compute(BudgetInput in) {
        long spendable = in.incomePaise() - in.fixedPaise() - in.savingsPaise();
        long pool = spendable - in.spentBeforeTodayPaise();
        long budget = pool > 0 ? pool / in.daysLeftIncludingToday() : 0;
        long spent = in.spentTodayPaise();
        long left = Math.max(0, budget - spent);
        long over = Math.max(0, spent - budget);
        long poolOver = Math.max(0, -pool);
        int percent = budget > 0 ? (int) Math.min(999, spent * 100 / budget) : (spent > 0 ? 999 : 0);
        Mood mood = pool <= 0 || over > 0 ? Mood.FAINTED
            : percent < 50 ? Mood.HAPPY
            : percent < 80 ? Mood.CALM
            : Mood.NERVOUS;
        return new DailyBudget(spendable, pool, budget, spent, left, over, poolOver, percent, mood);
    }
}
```

```java
package in.gullak.budget;

import java.time.LocalDate;
import java.util.Optional;
import java.util.UUID;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Repository;

@Repository
class CycleRepository {
    private final JdbcClient jdbc;

    CycleRepository(JdbcClient jdbc) {
        this.jdbc = jdbc;
    }

    Optional<Cycle> findCovering(UUID userId, LocalDate date) {
        return jdbc.sql("select start_date, end_date from cycles where user_id = ? and start_date <= ? and end_date >= ?")
            .params(userId, date, date)
            .query((rs, n) -> new Cycle(rs.getObject("start_date", LocalDate.class), rs.getObject("end_date", LocalDate.class)))
            .optional();
    }

    Optional<LocalDate> latestEndBefore(UUID userId, LocalDate date) {
        return jdbc.sql("select max(end_date) from cycles where user_id = ? and end_date < ?")
            .params(userId, date)
            .query((rs, n) -> rs.getObject(1, LocalDate.class))
            .optional();
    }

    /** Returns true when this call created the row; false when another request already had. */
    boolean insertIfAbsent(UUID userId, Cycle cycle) {
        return jdbc.sql("""
                insert into cycles (id, user_id, start_date, end_date) values (?, ?, ?, ?)
                on conflict (user_id, start_date) do nothing
                """)
            .params(UUID.randomUUID(), userId, cycle.start(), cycle.end())
            .update() == 1;
    }
}
```

```java
package in.gullak.budget;

import in.gullak.common.log.Events;
import in.gullak.profile.Profile;
import java.time.LocalDate;
import java.util.Optional;
import java.util.UUID;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Service;

@Service
public class CycleService {
    private static final Logger log = LoggerFactory.getLogger(CycleService.class);

    private final CycleRepository cycles;

    CycleService(CycleRepository cycles) {
        this.cycles = cycles;
    }

    /**
     * The cycle covering {@code today}, created on first use. After a payday change the current cycle
     * keeps its end date; the next one starts the day after it and ends the day before the new payday.
     */
    public Cycle current(UUID userId, LocalDate today, Profile profile) {
        Optional<Cycle> existing = cycles.findCovering(userId, today);
        if (existing.isPresent()) {
            return existing.get();
        }
        Cycle natural = CycleCalculator.containing(today, profile.paydayRule(), profile.paydayDay());
        LocalDate start = cycles.latestEndBefore(userId, today)
            .map(end -> end.plusDays(1))
            .filter(s -> s.isAfter(natural.start()))
            .orElse(natural.start());
        Cycle cycle = new Cycle(start, natural.end());
        if (cycles.insertIfAbsent(userId, cycle)) {
            log.info("{} user={} days={}", Events.CYCLE_OPENED, userId, cycle.days());
        }
        return cycles.findCovering(userId, today).orElse(cycle);
    }
}
```

```java
package in.gullak.budget;

import in.gullak.common.time.Ist;
import in.gullak.content.GullakLines;
import in.gullak.profile.FixedCostService;
import in.gullak.profile.Profile;
import in.gullak.profile.ProfileService;
import java.time.Clock;
import java.time.LocalDate;
import java.time.temporal.ChronoUnit;
import java.util.UUID;
import org.springframework.stereotype.Service;

@Service
public class BudgetService {
    private final ProfileService profiles;
    private final FixedCostService fixedCosts;
    private final CycleService cycles;
    private final SpendTotalsRepository totals;
    private final Clock clock;

    BudgetService(ProfileService profiles, FixedCostService fixedCosts, CycleService cycles,
                  SpendTotalsRepository totals, Clock clock) {
        this.profiles = profiles;
        this.fixedCosts = fixedCosts;
        this.cycles = cycles;
        this.totals = totals;
        this.clock = clock;
    }

    public TodayResponse today(UUID userId) {
        Profile profile = profiles.get(userId);
        LocalDate today = Ist.today(clock);
        Cycle cycle = cycles.current(userId, today, profile);
        long before = totals.spent(userId, Ist.startOf(cycle.start()), Ist.startOf(today));
        long spentToday = totals.spent(userId, Ist.startOf(today), Ist.startOf(today.plusDays(1)));
        int daysLeft = (int) ChronoUnit.DAYS.between(today, cycle.end()) + 1;
        DailyBudget b = BudgetCalculator.compute(new BudgetInput(
            profile.incomePaise(), fixedCosts.totalFor(userId), profile.savingsPaise(), before, spentToday, daysLeft));
        return new TodayResponse(today, b.budgetPaise(), b.spentTodayPaise(), b.leftPaise(), b.overPaise(),
            b.poolOverPaise(), b.mood(), GullakLines.line(profile.personality(), b), daysLeft,
            cycle.start(), cycle.end());
    }
}
```

```java
package in.gullak.security;

import static org.assertj.core.api.Assertions.assertThat;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.get;
import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;

import com.jayway.jsonpath.JsonPath;
import in.gullak.support.ApiTest;
import in.gullak.support.TestUser;
import java.time.Instant;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.springframework.boot.test.system.CapturedOutput;
import org.springframework.boot.test.system.OutputCaptureExtension;
import org.springframework.http.MediaType;

@ExtendWith(OutputCaptureExtension.class)
class LogRedactionApiTest extends ApiTest {

    @Test
    void aFullSessionLeavesNoSensitiveDataInTheLogs(CapturedOutput out) throws Exception { // LOG-05, SEC-01
        TestUser u = exampleUser();
        addFixedCost(u, "Landlord Sharma", 1_234_500);
        seedSpend(u, 777_700, Instant.parse("2026-10-23T03:00:00Z"));
        mvc.perform(get("/api/v1/budget/today").with(auth(u)));
        String refreshed = mvc.perform(post("/api/v1/auth/refresh").contentType(MediaType.APPLICATION_JSON)
                .content("{\"refreshToken\":\"" + u.refreshToken() + "\"}"))
            .andReturn().getResponse().getContentAsString();
        String newAccess = JsonPath.read(refreshed, "$.accessToken");

        String logs = out.getOut() + out.getErr();
        assertThat(logs)
            .doesNotContain(u.email())
            .doesNotContain(u.accessToken())
            .doesNotContain(u.refreshToken())
            .doesNotContain(newAccess)
            .doesNotContain("Landlord Sharma")
            .doesNotContain("1234500")
            .doesNotContain("777700")
            .doesNotContain("5000000");
    }

    @Test
    void businessEventsAreLoggedWithIdsOnly(CapturedOutput out) throws Exception { // LOG-03
        TestUser u = exampleUser();
        mvc.perform(get("/api/v1/budget/today").with(auth(u)));
        String logs = out.getOut();
        assertThat(logs).contains("auth.otp.requested").contains("auth.otp.verified user=" + u.id());
        assertThat(logs).contains("profile.updated user=" + u.id());
        assertThat(logs).contains("profile.fixed_cost.changed user=" + u.id());
        assertThat(logs).contains("cycle.opened user=" + u.id() + " days=31");
    }

    @Test
    void everyErrorHasTheStandardShape() throws Exception { // ERR-01
        TestUser u = signIn();
        String[] bodies = {
            mvc.perform(get("/api/v1/budget/today").with(auth(u))).andReturn().getResponse().getContentAsString(),
            mvc.perform(get("/api/v1/budget/today")).andReturn().getResponse().getContentAsString(),
            mvc.perform(get("/api/v1/me/fixed-costs/not-a-uuid").with(auth(u))).andReturn().getResponse().getContentAsString(),
            mvc.perform(post("/api/v1/auth/refresh").contentType(MediaType.APPLICATION_JSON).content("{}"))
                .andReturn().getResponse().getContentAsString()
        };
        for (String body : bodies) {
            assertThat((String) JsonPath.read(body, "$.code")).isNotBlank();
            assertThat((String) JsonPath.read(body, "$.message")).isNotBlank();
            assertThat(body).doesNotContain("Exception").doesNotContain("at in.gullak");
        }
    }
}
```

`GET /api/v1/me/fixed-costs/not-a-uuid` has no GET mapping with an id, so it exercises the 405 path; both paths must keep the shape.
